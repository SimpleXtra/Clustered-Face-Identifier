# Clustered Face Identifier

A model pipeline for identifying people in a video using YOLO and DBSCAN-clustered Facenet512 embedding.

## Installation Guide

This application was tested in Windows using Python 3.13.11.

1. Clone the repository.
2. Install the dependencies with `pip install -r requirements.txt`

> To enable CUDA acceleration (especially for model training), refer to [PyTorch's website](https://pytorch.org/get-started/locally/) and install the relevant version of `torch` and `torchvision`.
